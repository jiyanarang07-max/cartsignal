
# CartSignal

## Project Overview
CartSignal is a checkout analytics and revenue
leakage detection tool for Indian D2C businesses.

## Problem Statement
Many small e-commerce businesses struggle to
identify why customers abandon checkout,
experience payment failures, or cancel orders.

## Our Solution
CartSignal analyses checkout data to identify
potential revenue leakage and recommend
business improvements.

## Key Features
- Checkout conversion analysis
- Payment failure analysis
- Revenue leakage estimation
- Customer behaviour insights
- Business recommendations
- Interactive analytics dashboard

## Tech Stack
- Python
- pandas
- SQLite
- Streamlit
- Git and GitHub

## Dataset
Synthetic Indian e-commerce checkout data
created for educational purposes.
